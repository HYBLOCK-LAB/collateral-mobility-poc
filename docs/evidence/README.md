# 실험 결과 데이터

[runs.csv](runs.csv)는 T1~T4 계측 원본에서 선정한 공개용 실행별 데이터이다. 공통 실험 기준은 [PR #14 병합본 4d9369c](https://github.com/HYBLOCK-LAB/collateral-mobility-poc/tree/4d9369c59ad4e2f60b03483caeca07a3b2246a6b)이며, 원본 배치 ID는 [프로젝트 README](../../README.md#코드와-재현-기준)에 있다.

- 모델·실험별 본 시도와 워밍업을 `phase`로 구분한다. `T_*`의 단위는 밀리초이고 빈 칸은 해당 지표의 측정값이 없음을 의미한다.
- 시간 통계는 해당 모델·실험의 본 시도 중 유효한 성공 표본을 대상으로 한다. P50·P95는 정렬 후 각각 ceil(0.50×n), ceil(0.95×n)번째 값을 사용한다.
- `T_E`는 X 확정 관측부터 Z 확정 관측까지의 시간이다. `T_R`은 응답 지연 후 원래 Y 요청의 결과와 업무 상태를 확인하기까지의 시간이며 타임아웃을 포함한다. `T_RA`와 `T_unavailable`은 B2의 계약별 재할당·사용 불가 구간이다.
- 원본 이벤트·설정·실행 환경은 별도 보관한다. 공개 CSV에는 로컬 경로와 내부 식별자를 포함하지 않았다. 실험 해석은 [최종 보고서](../report.pdf)를 참조한다.
